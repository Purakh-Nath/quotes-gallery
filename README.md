# Quotes Gallery App

A React application that displays a beautiful gallery of inspirational and motivational quotes. The application fetches quotes from the free API and presents them in a responsive, modern interface with a dark theme.

## Features

- Fetches quotes from freeapi.app API  
- Responsive grid layout that adapts to different screen sizes  
- Dark theme with smooth hover effects  
- Displays quote content, author, tags, and character count  
- Loading state while data is being fetched  
- Clean and modern UI built with Tailwind CSS
